# Ashirbad's personal website

This folder contains a simple multi-page website.

## Pages
- `index.html` — About / homepage
- `projects.html` — Projects
- `blogs.html` — Blogs
- `courses.html` — Courses
- `contact.html` — Contact

Keep all files in the same folder. The homepage photo is `profile.jpg`.

To publish, upload all files and `profile.jpg` to the root of the GitHub Pages repository, replacing the previous files.
