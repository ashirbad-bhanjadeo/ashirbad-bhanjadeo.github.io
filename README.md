# Ashirbad — Personal Website

A responsive, Apple-inspired personal website and blog built with plain HTML, CSS and JavaScript. No framework, build step, paid service or backend is required.

## Files

- `index.html` — all page content and sections
- `styles.css` — layout, colours, responsive design and theme styles
- `script.js` — mobile navigation, dark-mode toggle, article filters and current year

## Run it on your computer

1. Extract this ZIP file.
2. Open the `ashirbad-personal-website` folder in VS Code.
3. Open `index.html` in a browser. For a better editing workflow, install the free **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**.

## Personalise before publishing

Open `index.html` and search for these placeholders:

- `YOUR_EMAIL@example.com` — replace with your public contact email.
- `YOUR_GITHUB` — replace with your GitHub username.
- `YOUR_LINKEDIN` — replace with your LinkedIn profile slug.

Also review the sample project descriptions, learning interests and starter blog topics. Keep claims accurate and replace starter content with your own work as it develops.

To change your name or the homepage headline, edit the text in the hero section of `index.html`.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Upload `index.html`, `styles.css` and `script.js` to the repository's root.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for the deployment to finish. Your website should be available at `https://YOUR-USERNAME.github.io`.

GitHub Pages may take a few minutes to publish after the first setup or a change.

## Notes

- Hosting is free for this static website on GitHub Pages under its applicable usage terms.
- The Google Fonts import requires an internet connection; the site still works with system fonts if it cannot load.
- The contact links use `mailto:`. There is no contact form backend.
- This is a static website. A full blog publishing system, comments, login or database would require additional services.
